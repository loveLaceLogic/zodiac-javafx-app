# Zodiac JavaFX App

A JavaFX desktop application that determines a user's zodiac sign based on their birth date.

## Features
- JavaFX GUI
- Event-driven programming
- Zodiac sign calculation
- Input formatting
- Secondary result window
- Custom application icon

## Technologies Used
- Java
- JavaFX
- Eclipse IDE

## How to Run

Use the following VM arguments:

```bash
--module-path /Users/kristinachaleunsak/Downloads/javafx-sdk-21.0.10/lib --add-modules javafx.controls,javafx.fxml
```
